# Security Policy

## Supported Versions

We currently support the latest version of EntryDesk for security updates. If you are self-hosting, please ensure you are pulling the latest changes from the `main` branch to receive the most up-to-date security patches.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in EntryDesk, please report it privately to the maintainers. You can reach out directly via GitHub private messaging or email to the core maintainers ([@ull0sm](https://github.com/ull0sm) and [@bugsNburgers](https://github.com/bugsNburgers)).

We will acknowledge receipt of your vulnerability report as soon as possible, and strive to send you regular updates about our progress. If a fix is verified, we will release an update and notify the community.
